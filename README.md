# Bir Dünya Dolusu Çiçek

`index.html` dosyasını tarayıcıda açarak hediyeyi yerel olarak izleyebilirsin. Yıldızlı sahne, lale animasyonu ve görseller siteyle birlikte gelir. Kurulum, harici bağımlılık ve ziyaretçi hesabı gerekmez.

## GitHub Pages ile yayınla

1. GitHub'da **lale-bahcesi** adında yeni, **Public** bir depo oluştur.
2. `index.html` içindeki `KULLANICI` değerinin iki geçtiği yeri GitHub kullanıcı adınla değiştir. Depo adın farklıysa `og:url` ve `og:image` adreslerindeki `lale-bahcesi` bölümünü de güncelle. Kapak adresi, herkese açık ve tam bir HTTPS adresi olmalı.
3. ZIP'ten çıkardığın dosyaları depo köküne yükle. `index.html`, `style.css`, `garden.js` ve `assets/` burada görünmeli. Web arayüzünde **Add file → Upload files** seçeneğini kullanabilirsin. `assets/` klasörünü koruyarak yükle ve **Commit changes** ile kaydet.
4. **Settings → Pages** altında **Deploy from a branch**, ardından **main** ve **/ (root)** seçeneklerini seçip kaydet. Yayın tamamlanınca **Visit site** bağlantısını aç.
5. Site adresini WhatsApp'ta önce kendine yapıştır. Başlık ve kapak göründüğünde bağlantıyı paylaş. Kapak gelmezse önce `og:image` adresini tarayıcıda açıp görselin erişilebilir olduğunu kontrol et ve WhatsApp'ta tekrar dene.

[GitHub Pages yayın ayarları](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
